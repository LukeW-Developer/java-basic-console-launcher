# Java Basic Console Launcher

## Overview

A Java console-based launcher project developed to further strengthen understanding of Java programming and console application development.

The project was inspired by an earlier launcher system I originally created in BATCH and later redeveloped in C# with a graphical user interface.

This version was designed as an experimental learning project focused on improving programming structure, modularity, and command handling within Java applications.

---

## Features

* Console-based launcher interface
* Menu-driven navigation
* Command execution concepts
* Structured modular application design
* Experimental utility functionality

---

## Technologies Used

* Java
* Console Application Development
* Object-Oriented Programming

---

## Purpose of the Project

This project was created to improve understanding of Java application development and experiment with recreating earlier software concepts using different programming languages and architectures.
